分支与 fallback 链

来源：Palantir Docs · Branching（2026-10-26 核对）。配套课程：第 2 课。

分支

  • 分支 = 指向该分支最新事务的指针，不存数据。
  • 非根分支有且只有一个父分支；子分支可从分支或任意事务创建。
  • 删除分支只删指针，事务保留；子分支改挂到父分支下。
  • 不能合并数据集分支。合并代码，再在目标分支上重新构建。
  • 同一分支内事务按开始/提交时间有序；跨分支没有顺序保证。

构建时的解析规则

构建分支 + fallback 链，例如 feature → develop → master。

对象规则
JobSpec构建分支 → 否则链上第一个发布了 JobSpec 的分支
输入构建分支 → 否则链上第一个存在的分支
输出事务总在构建分支；分支不存在则从链上第一个 fallback 创建，无 fallback 则建根分支

保证

  • 构建只改构建分支。
  • 构建不会在输入数据集上创建分支。
  • fallback 链必须和相关数据集的分支祖先关系兼容，否则解析失败。
