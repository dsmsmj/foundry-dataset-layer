# 误解：把输出的建分支规则套到了输入上

学习者回答"输入没有 feature 分支会读 develop，没有就读 master，再没有就作为根分支"。前半段正确；"作为根分支"是**输出**的规则（输出分支不存在、又没有 fallback 时才会建根分支）。构建**从不在输入数据集上创建分支**。学习者也没有回答"会不会给输入建 feature 分支"，并且收尾题 3 只复述了结论，没有说出原因（构建只改构建分支）。

**Status**：2026-10-26 已指出，待学习者复述确认。
**Implications**：第 3 课开头再出一道区分输入/输出解析规则的检索题；讲构建时强调"读输入、写输出"这条主线。
